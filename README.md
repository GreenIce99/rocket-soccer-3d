# Rocket Soccer 3D

A Vite + Three.js arcade soccer game.

## Run locally
1. Install Node.js.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## GitHub Pages
The Vite base path is configured for the repository name `rocket-soccer-3d`.
The GitHub Actions workflow should build with `npm ci` and `npm run build`, then publish `dist`.

## Controls
- W / Up Arrow: accelerate
- S / Down Arrow: reverse / brake
- A / Left Arrow: steer left
- D / Right Arrow: steer right
- Shift: boost (while accelerating)
- Space: jump
- R: reset positions
- C: switch camera
- Escape: pause
